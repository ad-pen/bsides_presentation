How do you build a safe one?

DEFENCE

What does not work

01
Improving the system prompt
02
Blocking words like "ignore previous instructions"
If the model can see it, the attacker can use it.
DEFENCE

What actually works

You cannot fix the model. Fix everything around it.
01
Clean the input where you can.
02
Keep untrusted text away from secrets.
03
A human approves anything you cannot undo.
04
Run code in a sandbox.
